## 📝 Descrição do Projeto
Modelo de IA criado em python e executado no Discord que ajuda pessoas reciclar e reusar lixo baseado em imagens de lixo comuns

## ✨ Principais Funcionalidades (Key Features)
- Funcionalidade 1: Permite que o usuário faça upload de imagem para um feedback instantâneo de maneiras de reutilizar o lixo especificado.
- Funcionalidade 2: Integração com a biblioteca discord.py para buscar uma interface mais acessível.

## 💻 Como Rodar/Instalar

### Pré-requisitos

Antes de começar, você precisará ter instalado:

- Biblioteca do Discord (py -3 -m pip install -U discord.py)
- Python 3.12 ou superior
- (Opcional) Visual Studio Code

### Rodando a aplicação

```bash
# Clone este repositório
git clone https://github.com/seu-usuario/nome-do-repositorio.git

# Entre na pasta
cd nome-do-repositorio

# Crie um ambiente virtual
python -m venv .venv

# Ative o ambiente virtual

# Windows
.venv\Scripts\activate

# Linux/macOS
source .venv/bin/activate

# Instale as dependências
pip install -r requirements.txt

# Execute o projeto
python main.py
```
